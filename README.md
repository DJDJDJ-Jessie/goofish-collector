# 闲鱼公开商品研究采集器

这是一个不依赖构建工具的 Chrome/Chromium MV3 扩展，面向“商业计划书、可研报告、标书、调研报告”等品类的公开竞品研究。主界面已经改为浏览器侧边栏，适合承载跨多个详情页的长期任务。

当前实现版本：`0.5.2`。

## 当前版本能做什么

- “采集当前详情页”只保存当前已经打开的商品详情页，不把搜索卡片当作最终商品记录。
- 打开商品详情页后点击一次，尽量补充商品文案、图片、类目、店铺名称、开店时长和商品好评率；服务类商品优先把详情属性区的“服务类型”（例如“金融”）写入唯一的“类目”字段。页面只提供平台内部 `categoryId`、没有公开类目名称时，类目留空，不把内部编号冒充类目。
- “采集当前店铺页”会读取店铺名称、账号页、地区、粉丝、关注、商品数、简介、开店时长、好评率、评价数，并滚动评价区域读取当前页面可加载的全部公开评价；评价图片会单独下载并嵌入 Excel。页面会显示当前店铺是否已有历史记录、上次采集时间和评价数量；首次采集或更新完成后直接显示“立即下载 Excel”按钮，也可以进入数据中心。
- 在“批量商品链接”中粘贴多个商品详情链接后，插件会在专用标签页中逐个打开详情页，再采集每个详情页上可见的字段。
- 在“搜索页跨页采集”中设置目标商品数和最多页数后，搜索页只负责发现商品详情链接；插件会在专用标签页中逐个打开详情页、校验页面类型和商品链接，采集完成后返回搜索页，再按当前页码点击下一页页码或分页控件。搜索列表尚未渲染出商品时会等待重试，不会把“0 条”直接标为完成。例如每页约 40 条、目标 100 条时，会跨约 3 个搜索页并访问 100 个商品详情页。
- 观察页面自身已经发出的搜索/详情 JSON 响应，作为 DOM 采集的补充。只发送响应中可识别的公开商品字段，不保存原始响应。
- 可以在侧边栏切换“页面详情模式”和“接口观察模式”。页面详情模式读取详情页已经渲染出来的文字、图片和店铺信息；接口观察模式只读取页面自身已经公开加载的 JSON/接口响应，再与页面内容合并。接口观察模式不直接调用闲鱼隐藏接口、不读取 Cookie、不生成签名；批量任务仍然会自动进入每一个商品详情页。
- 生成真正的 `.xlsx` 文件，包含“商品数据”“图片索引”“店铺资料”“店铺评价”“评价图片”“说明”六个工作表。
- “商品数据”主表固定为 18 列，顺序是：商品ID、商品链接、主图文件名、商品图片（已嵌入）、商品文案、价格、类目、店铺名称、卖家账号页、卖家地区、粉丝数、关注数、卖家商品数、店铺简介、开店时长、商品好评率、店铺评价数、采集时间；商品标题、来源页面、数据来源等内部辅助字段不再出现在主表。
- 导出时下载图片并把真实图片二进制嵌入 Excel；商品主表放每个商品的第一张成功下载图片，图片索引表放每张图片。
- 图片文件名会按“商品标题_店铺名_商品ID_图序号.扩展名”生成，并在主表/图片索引表中显示。
- 店铺评价图片按“店铺名_评价序号_图序号.扩展名”生成；“评价图片”表逐张显示真实图片和下载状态。
- 商品图片默认按“全部（商品图最多 1000 张）”处理，也可以在侧边栏设置每个商品最多 3、5 或 10 张；已读取的店铺评价图片不与商品图共用这个上限，会单独全部处理。
- 支持任务完成后自动下载或手动下载；设置里可以填写浏览器下载目录下的相对文件夹、文件名模板、图片上限和“另存为”开关。
- 任务完成、停止或失败会在侧边栏显示结论；允许通知时会弹出系统通知。历史任务保存在本地，可重新导出或删除。
- 卖家资料补充不再静默吞掉失败：商品详情仍会保存，但侧边栏/任务页会明确显示账号页补充失败或设置已关闭。
- 侧边栏提供“一键导出页面诊断包”，会自动提取当前动态 DOM、可见文字、商品链接、图片地址、规范化记录和经过字段脱敏的公开接口响应，打成 ZIP，方便后续精确适配闲鱼页面，不需要用户手动复制 F12。

## 安装

1. 使用 Chrome、Edge 或其他 Chromium 浏览器打开 `chrome://extensions/`（Edge 可打开 `edge://extensions/`）。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `D:\CodeSpace\goofish-collect`。
4. 登录闲鱼并打开 `https://www.goofish.com/`，点击浏览器工具栏里的“闲鱼研究采集器”图标，Chrome 会打开侧边栏。

当前项目根目录已经清理掉以下划线开头的诊断目录，Chrome 可以直接点击“重新加载”。诊断副本放在 `D:\CodeSpace\_diagnostic-review-20260806`，不属于扩展加载目录。

如果侧边栏提示 `Could not establish connection. Receiving end does not exist.`，先在扩展管理页点击“重新加载”，再回到闲鱼刷新当前标签页。侧边栏会尝试自动补注入内容脚本；如果仍失败，请确认当前标签页是 `https://*.goofish.com/`，而不是浏览器设置页、新标签页或其他站点。

## 推荐使用流程

1. 在闲鱼搜索一个具体品类，例如“可研报告”“商业计划书”“投标书”。
2. 如果只研究一个商品，打开其详情页后在侧边栏点击“采集当前详情页”；按钮会先判断当前是否真的为详情页。
3. 如果有一批商品详情链接，把链接粘贴到“批量商品链接”文本框中；插件会逐个打开链接采集。
4. 如果要按搜索结果批量研究，打开搜索结果页，在“搜索页跨页采集”中设置目标商品数和最多采集页数，再启动任务。搜索卡片只用于找链接，最终保存的是逐个打开后的详情页。
5. 如果要研究某个同行店铺，打开其 `/personal?userId=...` 店铺/账号页，在侧边栏点击“采集当前店铺页”，等待评价区域加载完成，然后直接点击店铺页上的“立即下载 Excel”；也可以点击“查看数据中心”。
6. 需要换关键词时重复以上流程。可以在“下载设置”中选择自动下载，也可以在任务结束后打开“数据中心”点击“下载 Excel”。导出过程会先下载商品图片和评价图片，再生成 Excel，图片较多时需要等待一段时间。

## 重要边界

- 代码不读取 `_m_h5_tk` 等 Cookie，不生成闲鱼 API 签名，不主动调用隐藏 API。
- 代码不拦截 WebSocket，不采集聊天内容、私信或其他与竞品商品研究无关的数据。
- 代码不上传到服务器，采集结果只保存在浏览器扩展的本地存储里。
- 页面结构、接口字段和平台规则会变化；如果某个字段为空，通常意味着该字段没有在当前页面公开显示，或者页面结构已经变化。当前版本已针对账号页 `infoTop` 只包含昵称、其它资料位于兄弟节点的结构做了作用域修复，并在 DOM/接口合并时防止空值覆盖有效值。
- 店铺资料字段按页面语义区域读取：账号页会等待昵称、统计、简介等公开资料连续两次保持一致后才合并。店铺简介是用户自定义文本，纯数字也会保留；只有在账号资料区域明确找到的简介节点才会写入，不能用“是不是数字”代替字段识别。
- 店铺页的“全部评价”以页面当前能加载到浏览器的公开评价为准；插件会自动滚动触发懒加载，但不会调用隐藏评价接口或猜测未公开内容。Excel 的“店铺资料”表会同时写入“已采集评价数”，便于核对页面展示的总数。
- 搜索列表页通常只展示标题、价格、缩略图、少量卖家信息；它在跨页模式中只作为“发现链接”的中间步骤，不会直接写入最终商品表。完整商品文案、商品页卖家信息来自详情页；店铺简介和账号公开评价来自详情页链接对应的 `/personal?userId=...` 卖家账号页。批量链接和搜索跨页模式都会自动打开商品详情页，随后按设置补充卖家账号页，再继续下一个商品。
- 图片 CDN 如果拒绝扩展程序访问，会在 Excel 的“图片下载状态”列标记失败原因；成功下载的图片会作为真实图片嵌入，而不是退回成只有链接。
- 为了避免一次导出占用过多内存，单次最多处理 1000 张商品图片；已读取的评价图片单独处理，异常页面最多保护性处理 20000 张。超出保护上限会在导出状态中提示。店铺评价文本和图片索引保存在扩展本地存储中。
- 使用时请遵守闲鱼的服务条款、 robots/访问规则和适用法律，保持人工触发、合理频率，不绕过验证码、登录限制、风控或访问控制。

## 要继续做精确适配，需要你提供什么

如果安装后“标题、价格、图片”能采集，但店铺/评价字段不完整，最有价值的是：

1. 一条搜索接口响应 JSON 的脱敏样本；
2. 一条商品详情接口响应 JSON 的脱敏样本；
3. 对应页面的截图，标出商品标题、价格、店铺简介、开店时长和评价所在区域；
4. 如果是店铺字段串位，请在出现问题的那个 `/personal?userId=...` 页面等待页面完全显示后，再点击“一键导出页面诊断包”。新诊断包会额外包含 `account-profile.json`，便于核对“解析出来的值”和实时 DOM 所属区域；优先提供一条出错店铺即可；
5. 不要提供 Cookie、Token、`sign`、完整请求 URL、私信/聊天内容或账号隐私信息。

拿到脱敏样本后，可以把字段映射从“通用启发式”改成闲鱼当前版本的精确映射，并增加店铺页的人工确认采集流程。
